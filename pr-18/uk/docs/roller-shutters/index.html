Текстові кроки та усунення несправностей

Покрокова інструкція

Waveshare керує мотором через пару реле, Hearth передає жести настінних кнопок, а Home Assistant об’єднує їх у керування ролетою. Нижче — текстова версія всіх кроків.

Перед початком

  • Встановіть OSELIA Hearth та Waveshare Modbus RTU Relay, перезапустіть Home Assistant.
  • Додайте плату реле через Serial або Network (TCP). Плати на одній шині повинні мати різні Modbus-адреси.
  • Для настінної кнопки потрібен Hearth, підключений до MQTT-брокера, з доступними сутностями входів event. Саму ролету можна створити й перевірити без кнопки.
  • Увійдіть як адміністратор, щоб бачити OSELIA Config.
  • Монтаж мотора має бути завершений. Підготуйте номери двох різних вільних реле тієї самої плати: для відкривання і закривання.

1. Створіть ролету з двох реле

  1. Відкрийте Settings → Devices & Services.
  2. На картці Waveshare Modbus RTU Relay натисніть Configure → Add a roller shutter.
  3. Заповніть поля:
ПолеЩо вказатиПриклад
NameЗрозуміла назва ролетиРолета вітальні
Relay boardПлата, до якої підключений моторЩитова (address 1)
Up relay (opens)Номер реле відкривання1
Down relay (closes)Номер реле закривання2
Up travel time (seconds)Час повного відкривання; поки можна 00
Down travel time (seconds)Час повного закривання; поки можна 00
  1. Збережіть форму (Submit). На пристрої плати з’явиться нова сутність cover.

Номери реле відповідають написам Relay 1, Relay 2, …. Значення у прикладі замініть на свої. Один канал не можна використовувати для обох напрямків або для двох ролет. Назви пунктів наведені англійською, як у поточному інтерфейсі інтеграцій.

2. Перевірте відкривання, зупинку й закривання

На сторінці пристрою плати відкрийте нову ролету. Послідовно перевірте Open → Stop → Close → Stop. Керуйте через сутність ролети. Вона узгоджує роботу двох напрямків.

Якщо напрямки переплутані, зупиніть рух і відкрийте Configure → Edit a roller shutter. Виправте номери Up / Down. Редагування зберігає сутність, історію та прив’язки.

3. Додайте керування відсотком відкриття

Цей крок необов’язковий: з нульовими часами Open / Close / Stop уже працюють.

  1. Виміряйте час повного відкривання від закритого положення.
  2. Окремо виміряйте час повного закривання від відкритого положення.
  3. У Configure → Edit a roller shutter внесіть обидва значення в секундах і збережіть.
  4. Виконайте повний хід до крайнього положення для синхронізації позиції.

Коли обидва часи більші за 0, доступне керування позицією. 0% — закрито, 100% — відкрито. Позиція оцінюється за часом роботи мотора; це не показ датчика. 24 і 26 секунд у демонстрації — лише приклад.

4. Призначте ролеті кімнату

  1. Settings → Devices & Services → Entities → знайдіть ролету → відкрийте її → ⚙.
  2. Вимкніть Use device area («Використовувати приміщення пристрою»).
  3. У полі Area виберіть кімнату, наприклад Вітальня, і натисніть Update.

Плата залишається у щитовій, а сутність ролети отримує власну кімнату. Якщо кімнати ще немає, створіть її в Settings → Areas, labels & zones. Кімната автоматизації або входу кнопки не визначає розташування картки ролети.

5. Прив’яжіть настінну кнопку

  1. У бічному меню відкрийте OSELIA Config.
  2. Увімкніть Listen for presses та затисніть потрібну фізичну клавішу.
  3. У повідомленні про знайдений вхід натисніть Use in form ↓. Вхід і жест підставляться у форму.
  4. Перевірте Input (wall-switch) і Gesture → Long press.
  5. У Target (light / cover) виберіть створену ролету cover, у Action — open.
  6. Задайте Name, наприклад «Вітальня — відкрити ролету», і натисніть Save binding.
  7. Повторіть для другої клавіші з дією close. За потреби створіть окрему прив’язку stop.

Кожна прив’язка створює звичайну автоматизацію Home Assistant. Повтор того самого налаштованого жесту під час руху за замовчуванням зупиняє ролету. Одинарне натискання можна залишити для світла. Подвійне працює лише якщо воно ввімкнене в прошивці; для цього прикладу достатньо довгого натискання.

6. Відкрийте панель мешканця

Якщо панель уже є, просто оновіть її. Якщо немає:

  1. Settings → Dashboards → Add dashboard → New dashboard from scratch → назвіть її OSELIA → Create.
  2. Відкрийте панель → ⋮ → Edit dashboard → ⋮ → Raw configuration editor.
  3. Замініть вміст на:
strategy:
  type: custom:oselia-resident
  1. Натисніть Save. Ролета з’явиться в кімнаті, заданій для її сутності.

Панель мешканця показує лише сутності, прив’язані до кнопок. Перевірте рух як із картки, так і з фізичної клавіші.

Якщо щось не з’явилося

СимптомЩо перевірити
Немає плати у форміСпочатку додайте плату через Configure → Add a relay board.
Форма не приймає каналиВони мають бути різними, у межах кількості каналів плати й не зайнятими іншою ролетою.
Немає повзунка позиціїВнесіть обидва часи повного ходу, більші за 0.
Немає події кнопкиПеревірте доступність Hearth, MQTT та Listen for presses.
Немає картки ролети на панеліЗбережіть прив’язку до цієї сутності в OSELIA Config; перевірте Automation health та оновіть панель.
Картка у щитовійУ налаштуваннях сутності cover вимкніть Use device area і задайте її Area.
